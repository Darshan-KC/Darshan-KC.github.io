# Darshan KC Portfolio v2

Professional portfolio for Darshan KC, built as a fully static Astro site for GitHub Pages.

## Stack

- Astro
- TypeScript
- Tailwind CSS
- React for isolated client-side interactivity
- Lucide Icons
- JSON data layer
- GitHub Actions deployment

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Architecture

The `v1/` directory is reference-only. Portfolio v2 must not import data, components, scripts, or runtime assets from `v1/`.
